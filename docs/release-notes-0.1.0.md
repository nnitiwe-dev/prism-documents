## PRISM Documents 0.1.0 — Phase 1 (PDF essentials)

The first release of PRISM Documents — an open-source, local-first document
workspace by PRISM Data Studio. Everything runs on your machine.

### Highlights

- **Open & view** PDFs with selectable text, search, zoom, and a navigation
  pane (table of contents / page list). Sharp rendering on Retina/HiDPI.
- **Merge** PDFs with drag-and-drop, first-page previews, drag-to-reorder, and
  an editable output name — lossless, text stays selectable.
- **Remove pages** with a visual page grid (click pages to remove) or by typing
  ranges; plus **split**, **rotate**, **reorder**, and **extract text**.
- VS Code–style shell with a command palette (⌘K / Ctrl+K).

### Install

Download your platform's installer below.

- **macOS** (`.dmg`) — drag to `Applications`, then right-click → **Open** the
  first time (the app isn't code-signed yet).
- **Windows** (`.exe`) — on SmartScreen, **More info → Run anyway**.
- **Linux** (`.AppImage`) — `chmod +x` it, then run.

First launch takes ~10s while the local engine unpacks.

### Notes

- Not yet code-signed, so first-launch OS warnings are expected.
- Scanned (image-only) PDFs have no selectable text until OCR arrives in Phase 2.
